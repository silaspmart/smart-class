# Análise de Requisito

### Requisitos Funcionais(RF)
- RF01 - O sistema deve permitir o cadastro de alunos
- RF02 - O sistema deve permitir consultar, editar e excluir dados dos alunos
- RF03 - O sistema deve registrar a entrada dos alunos
- RF04 - O sistema deve registrar a saída dos alunos
- RF05 - O sistema deve controlar a frequência dos alunos
- RF06 - O sistema deve registrar faltas automaticamente quando não houver registro de presença 
- RF07 - O sistema deve permitir a consulta do histórico de frequência dos alunos
- RF08 - O sistema deve gerar relatórios de presença e faltas
- RF09 - O sistema deve permitir o cadastro de usuários responsáveis pela administração
- RF10 - O sistema deve permitir login para acesso às funcionalidades administrativas


### Requisitos Não Funcionais(RNF)
- RNF01 - O sistema deve possuir interface simples e intuitiva
- RNF02 - O sistema deve armazenar os dados em banco de dados
- RNF03 - O sistema deve garantir a segurança das informações dos alunos
- RNF04 - O sistema deve responder às consultas em tempo adequado
- RNF05 - O sistema deve estar disponível durante o horário de funcionamento da instituição
- RNF06 - O sistema deve permitir acesso por computadores com navegador web/mobile
- RNF07 - O sistema deve manter a integridade dos dados cadastrados 

### Regras de Negócio (RN)
- RN01 - Cada aluno deve possuir um cadastro único 
- RN02 - A entrada e a saída devem ser registradas com data e horário.
- RN03 - Apenas usuários autorizados poderão alterar ou excluir informações
- RN04 - O cálculo da frequência deve ser realizado automaticamente pelo sistema
- RN05 - Os relatórios deve apresentar informações atualizadas sobre presença e faltas
