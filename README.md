# Sistema de Controle de Entrada e Saída de Alunos

Sistema desenvolvido para auxiliar instituições de ensino no gerenciamento da frequência dos alunos.

## Funcionalidades

- Cadastro de alunos
- Registro de entrada e saída
- Controle de frequência
- Registro de faltas
- Consulta de histórico

## Objetivo

Facilitar o acompanhamento da presença dos alunos, tornando o controle mais rápido, organizado e eficiente.

## Tecnologias Utilizadas

- Node.js — Ambiente de execução
- TypeScript — Linguagem tipada
- PostgreSQL — Banco de dados relacional
- TypeORM — ORM para banco de dados
- BCrypt — Criptografia de senhas

## Como rodar o projeto

Antes de começar, certifique-se de ter instalado na sua máquina:

- Node.js
- PostgreSQL

### Passo a passo

**Instale as dependências do projeto**

npm install

**Inicie o servidor em modo de desenvolvimento**

npm run dev
